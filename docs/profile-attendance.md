# 个人资料与双考勤

用户澄清：微信截图仅参考“编辑资料”打开后的个人资料页；不重做个人中心主页。继续UniApp Vue3 H5，无移动打包。

资料页：全屏标题+返回、微信式分组行。头像（本地上传并压缩/默认官方库洛米）、名字、性别、地区、手机号、微信号、签名逐项编辑。手机号和微信号只是联系资料，无绑定或身份认证宣称。不复制截图个人信息，不添加无关的微信钱包等功能。旧昵称签名兼容。

教学页：去除顶部品牌块和营销文案，课表去除大插画横幅，采用白/灰内容面与少量紫色操作，保留个人中心现有封面布局。

课程考勤：按月/日、状态筛选（全部、待上课、上课中、正常、迟到、早退、漏卡、请假、取消）；当天真实打卡；完成课程补录实际时间与原因，展示修正来源及原记录，未来时间拒绝，按实际时间统计迟到早退。标记已完成仅计一次薪，工资仍按约定时长。取消/请假不计薪。

上下班考勤：每天一组签到签退。按月份显式设置班次时间、工作日、开始生效日期及5分钟宽限；无配置时不判迟到/缺卡并引导设置。不支持跨日班次。记录保存计划快照，修改设置不改变已有记录。未打卡的已结束工作日显示漏卡。补卡必须填写原因、起止不能倒序/未来；全日请假不自动扣薪。可撤销记录，需确认。记录和课程分开存储与统计，均可CSV导出及JSON备份。

验证：规则测试覆盖独立计薪、迟到边界、缺签退、双击、历史规则快照、未来/非法补卡、请假冲突、备份校验和个人资料增量更新。H5构建、移动视口及数据持久化流程。
## 本轮验收
