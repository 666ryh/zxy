# UniApp + Vue3 / H5 迁移

用户要求：UniApp + Vue3，支持H5；替换手绘库洛米为官方来源图片；个人主页借鉴网易云音乐的封面、头像、统计、内容分区。保持紫色及现有教师功能，仅网页验收，不打APK或HAP。

## 设计
以DCloud官方uni-preset-vue的vite分支为构建参考，统一DCloud包版本3.0.0-5020620260917001，Vue3.4.21。页面在src/pages/index/index.vue；拆分个人主页、表单对话框及教学页面组件；业务规则移至src/domain；共享Vue响应式状态在src/store.js；保留Node验证码服务。

主页：深紫全幅封面（官方角色图与夜空纹理）、圆形悬浮头像、可编辑昵称签名、教学数据三列、主页/授课记录/常用服务三页签。将“歌单”式内容集合改成课表/学生/薪资入口，不制造音乐播放或社交数据。保留手机号客服、备份、邮箱登录。

数据：相同H5源和原localStorage键，首次读取兼容原访客与邮箱数据；严禁覆盖旧数据。保持18项业务/认证测试，补充存储迁移测试。H5文件导入导出为浏览器适配器，后续鸿蒙使用UniApp能力及真机验证，不声称本轮已支持原生鸿蒙。

## 执行
1. 原业务迁移src/domain并保留回归测试，存储读取/写入先测试。
2. UniApp脚手架、Vue状态层、真实表单及所有五页功能迁移。
3. 个人主页设计和官方素材替换，旧手绘资源退出运行入口。
4. H5构建、移动浏览器流程与截图验证。维持4173预览地址和旧hash兼容入口，不生成移动安装包。
