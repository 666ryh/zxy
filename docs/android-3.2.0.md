# 艳の辉 3.2.0

用户端 Android APK：`releases/yan-no-hui-3.2.0.apk`。

包含当前云端账号同步、豆包 AI 和应用内人工客服。打开辉辉后点击“转人工”，消息发送到辉辉客服工作台，人工回复在应用内显示。用户端和客服端使用不同包名，可以同时安装，登录会话彼此独立。

保留用户端包名 `cn.kejian.teacher` 与原签名，versionCode 320。可覆盖安装 3.1.1，勿先卸载以免清除旧本机数据。首次打开需联网；旧版本机数据可从返回键菜单进入并导出。

构建：`npm test`、`npm run build:apk`。发布到 GitHub Releases 的 APK 附 SHA-256 校验文件。打包脚本验证签名、内置资源及路由；无已连接安卓设备时不代表通过真机安装测试。
