# QQ邮箱注册与登录（网页测试）

发件人已配置为2546619708@qq.com，服务smtp.qq.com，端口465，TLS加密，使用QQ邮箱SMTP授权码。用户提供的授权码仅存在`server/.env.local`，未提交Git、未编译进前端。后端自动读取该文件；不使用VITE_环境变量存放任何密钥。

## 测试入口
`npm run preview` 后打开 http://127.0.0.1:4173/ 。若已进入访客模式，使用“我的→常用服务→邮箱登录/注册”。

1. 输入接收验证码的QQ邮箱（也接受其他合法邮箱）。
2. 点击发送验证码，查看收件箱或垃圾邮件。
3. 输入6位验证码并点击验证并登录。首次验证自动注册，以后同邮箱登录同一账号。

验证码5分钟有效，60秒重发间隔，最多5次错误，每个IP每小时最多10次发送。真实邮件模式不向接口返回验证码。发送完成前验证码不可使用，发送失败不会创建账号。

账号资料与会话存在`server/data/accounts.json`（Git忽略）。登录Cookie为HttpOnly、SameSite=Strict，有效7天；服务器只保存令牌哈希。重启后账号/会话保留，退出登录使会话永久失效。验证码保存在内存中，重启需重新获取。

## 配置维护
使用`.env.example`作为格式参考，私密值填写到`server/.env.local`，重启预览服务生效。

`npm run check:mail`只验证SMTP加密连接和认证，不发送邮件，不输出授权码。不要把该配置文件复制到src/static、发布目录或GitHub。AUTH_DEV_MODE默认关闭；SMTP未配置时发送功能不可用，不伪装成已发送。

## 数据与部署范围
这轮只实现邮箱账号注册和登录。教学记录、头像、背景等仍是原来的本机数据，没有云同步；新邮箱不会自动占用访客数据，可通过教学备份自行迁移。

当前是单进程本机预览。公网部署前需明确HTTPS域名、生产Cookie配置和数据库运维，不能直接把开发Vite端口暴露到公网。

## 验证
