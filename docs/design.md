# 课笺：教师个人安卓应用

用户目标：教师独立管理学生、安排课程、统计自己的课酬和出勤。交付位置 F:\teacher；安卓 APK，中文、离线、无账号。

## 参考项目
- https://github.com/namtudev/tutor_zone ：Flutter 个人家教工具，学生、授课记录、时薪、收入和收款。未检测到明确许可证，不复制代码。
- https://github.com/KunLiam/Kexintong ：Windows 排课与课酬统计，参考排课冲突和分学生定价。
- https://github.com/Hoodas101/starclass ：机构管理平台，MIT，功能过重，仅参考按课程结算思路。

## 方案
采用 Android Java Activity + 打包的 HTML/CSS/JS。安卓原生文件保存和系统文件选择器负责数据与备份，浏览器可预览同一界面。无需服务器与第三方运行库。相比 Flutter/React Native，当前单人离线表单和统计需求不需要额外框架；相比纯原生，便于快速验证全部手机交互。

## 交互与数据
- 课表：日期选择、七日条、当日课程时间线、手动排课、连续每周重复最多 12 周、修改未完成课程、取消、删除确认、上课打卡、下课完成、补录完成。
- 学生：姓名、科目、时薪、联系方式、备注；归档保留历史。
- 薪资：月度已赚课酬、已收/待收、教学时长、课程明细与 CSV 导出；课酬=课程约定分钟×课程时薪/60，以分为单位四舍五入。只统计已完成课程；课程保存时快照单价，后续调价不改变历史。
- 考勤：教师个人按课程的打卡记录；记录实际起止时间；已完成可补录；未来课程禁止打卡和完成。月度统计出勤天数、完成节数、迟到次数（超过计划开始5分钟）、请假节数。迟到不自动扣薪。请假和取消不计薪。
- 备份：JSON 导出/校验导入；导入需确认覆盖。默认空数据，可显式加载演示数据。保存失败保留原数据并显示错误。
- 单教师时间冲突检测，取消和请假不占用时间。跨日课第一版不支持。

## 界面
浅灰白底 #F5F7F6，墨绿 #185C4C，文本 #182A25，次要文本 #52655D，线条 #DFE7E2，橙色 #A45A19。系统中文字体；日期和课表为视觉中心，48px触控目标、底部四页导航、原生表单控件。抽屉表单、清晰空状态、错误提示与删除确认。

## 校验
Node 内置测试覆盖金额精度、时间冲突、重复排课原子性、考勤状态、未来记录、备份校验与历史价格。浏览器检查创建学生→排课→打卡/补录→薪资→备份往返及小屏布局。Android SDK 编译、签名验证；有设备时再运行真机验证。
