## 邮箱发送
当前开发模式：点击获取验证码，页面显示开发码并注明**未发送邮件**。此模式仅供本机验收，不是生产身份认证。

已经接入 Nodemailer SMTP 发送适配器；真实发信需要设置 `.env.example` 中的变量（文件本身不会被自动读取）：
```powershell
$env:SMTP_HOST='smtp.example.com'
$env:SMTP_PORT='465'
$env:SMTP_SECURE='true'
$env:SMTP_USER='your-email@example.com'
$env:SMTP_PASS='邮箱SMTP授权码'
$env:SMTP_FROM='your-email@example.com'
npm run preview
```
SMTP配置后不向前端返回验证码。验证码5分钟有效、60秒可重发、5次错误限制、每IP每小时最多10次；会话HttpOnly/SameSite Cookie，登出使其失效。验证码和会话保存在本地服务内存，重启后需重新登录。未配置SMTP时生产模式拒绝启动。不要将SMTP密码发在聊天或提交到Git。

数据目前存于浏览器localStorage，无云同步；登录只是本机功能验收与账号隔离，不等同于对设备拥有者加密。不同标签页建议不要同时编辑同一数据。正式部署前需服务器数据存储、HTTPS、生产邮件与账号管理。
