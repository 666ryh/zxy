# 辉辉自动回复

当前版本替代QQ/微信跳转：点击悬浮辉辉或个人中心客服入口，打开应用内聊天。

回复使用用户指定的十句话，全部原样保留（包括第三句开头的s），随机选择且不连续重复。标注“自动回复·趣味聊天”，不宣称真实人工、语义理解或大模型服务。

输入1～500字，每条输入立即配对一条回复。记录按原访客/登录邮箱隔离保存在浏览器，最多最近100条（50轮）。支持清空确认；保存失败保留输入、原记录并提示未发送。消息使用Vue文本渲染，不执行输入HTML。

代码：src/domain/huihui.js（语料与选择规则）、src/components/HuihuiSupport.vue（聊天窗口）。增加回复只需修改REPLIES数组。

验证：36项测试通过；浏览器实测发送、避免重复、刷新恢复；已移除QQ服务配置和跳转代码。本轮未打包。
