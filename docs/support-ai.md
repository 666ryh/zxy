# 辉辉 AI 与人工微信（云端更新）

辉辉使用服务器端豆包接口生成真实回复，模型 `doubao-seed-2-0-mini-260428`。API Key 仅保存在服务器 `server/.env.local`，不进入源码、浏览器或 APK。配置字段为 `DOUBAO_API_KEY`、`DOUBAO_MODEL`、`DOUBAO_BASE_URL`。

登录后可以发送最多 500 字的提问。后端校验会话及账号，只将最近 20 条聊天发送给豆包，不读取教学档案。每账号最多同时一个请求、每小时 30 次，调用超时 45 秒；失败保留输入，不以预设语句冒充 AI 回答。回复最多保存 4000 字，最近 100 条聊天沿用账号云同步。切账号或其他设备修改聊天时，旧请求不能覆盖新的聊天记录。

“转人工”不需要登录：复制微信号 `ryh520zxy1314` 后打开微信，由用户搜索添加。个人微信号不支持在本应用中直达指定聊天。新 APK 使用固定目标的原生微信入口；网页使用 `weixin://`，浏览器可能限制唤起，始终显示可手动复制的微信号。不会自动发送消息。

本次按用户要求只发布云端，不生成 APK。3.1.1 及更早 APK 没有原生微信入口，且会拦截外部协议；在旧包中可以复制微信号，再手动打开微信。原生唤起代码已准备，需未来重新打包安装才生效。网页 AI 更新由正式站提供。

本地验证：`npm test`、`npm run build:h5`、`npm run build:apk`。微信真机唤起需在安装微信的安卓/兼容设备上验证，当前未连接手机。
